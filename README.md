Colorvision project

## Description

**version 1.0**

My project compares colors using their RGB values to determine if it would be difficult to differentiate such colors as a red-green color deficient/blind person.

First, the user will the prompted to enter a small number of colors. For the colors,
the user will be prompted to enter the red, green, and blue values (RGB). 0 to 255
values accepted and values outside of this range will display an error message.
Next colors entered will be compared by calculating how different given RGB
values are. Difference scores will be calculated by the difference between several
red, green, and blue values. These values can be separated between output
categories that can be along the lines of easy, moderate, and difficult
distinguishability. User feedback can then be provided by recommending
increasing differences between values for better distinguishability
